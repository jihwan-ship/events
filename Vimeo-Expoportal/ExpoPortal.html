시즌 중에 필요한 정보를 빠르게 찾아보세요.

검색 결과 0개

  1. ✦ Vimeo Ask AI 사용 방법

    Ask AI는 현재 선택한 영상의 내용을 기반으로 질문에 답변합니다. 전시 참가사의 영상을 더 깊이 이해해보세요.

    1. 1
      영상 상세 페이지로 이동

      관심 있는 영상을 클릭하여 상세 페이지로 갑니다.

    2. 2
      Ask AI 버튼 클릭

      영상 플레이어 안에 있는 반짝이는 아이콘을 클릭합니다.

    3. 3
      영상 내용에 대해 질문하기

      해당 영상의 내용을 기반으로 궁금한 점을 자유롭게 질문합니다.

    4. 4
      AI의 답변 확인

      영상의 자막, 음성, 시각적 내용을 종합하여 해당 영상에 기반한 답변을 제공합니다.

    꼭 확인해주세요!
    • Ask AI는 포털 전체를 검색하는 기능이 아닙니다.
    • 현재 시청 중인 개별 영상의 내용에 대해서만 답변합니다.
    • 다른 영상이나 다른 주제에 대한 검색은 일반 검색 기능을 이용해주세요.

  2. Vimeo 언어 및 더빙 변경 방법

    Vimeo 영상에서는 원하는 언어의 자막과 더빙(음성)을 선택하여 시청할 수 있습니다.

    1. 1
      영상을 재생합니다

      보고 싶은 영상을 선택하고 재생합니다.

    2. 2
      자막 또는 설정 버튼을 클릭합니다

      자막(CC) 버튼은 자막만, 설정 버튼은 자막과 더빙을 모두 바꿀 수 있습니다.

    3. 3
      원하는 언어를 선택합니다

      열린 메뉴에서 원하는 언어를 선택합니다.

    4. 4
      선택한 언어로 영상 시청

      선택한 언어의 자막 또는 더빙이 적용되어 재생됩니다. 다른 언어로 바꾸려면 같은 방법으로 다시 선택하세요.

    꼭 확인해주세요!
    • 영상마다 제공되는 자막 언어와 더빙(음성) 언어가 다를 수 있습니다.
    • 자막이 보이지 않는 경우 자막(CC) 버튼이 활성화되어 있는지 확인해주세요.
    • 더빙(음성) 변경은 설정 메뉴에서만 가능합니다.
    • 자막이나 더빙을 끄고 싶다면 각 메뉴에서 ‘끄기’ 또는 ‘원본 언어’를 선택해주세요.
